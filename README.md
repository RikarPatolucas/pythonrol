# 🧙‍♂️ Juego de Rol en Python – Rikarpatolucas RPG

Este es un juego de rol por turnos hecho en Python. Incluye personajes, hechizos, combates, enemigos y una historia épica ambientada en el mundo de Damasco. Está en desarrollo activo y es un proyecto personal para aprender programación modular, diseño de juegos y organización de código.

## 🚀 Cómo ejecutar el juego

1. Clona el repositorio:
   ```bash
   git clone https://github.com/RikarPatolucas/pythonrol.git
   cd pythonrol
   ```

2. (Opcional) Crea un entorno virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # en Linux/macOS
   .\venv\Scripts\activate  # en Windows
   ```

3. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```

4. Ejecuta el juego:
   ```bash
   python main.py
   ```
